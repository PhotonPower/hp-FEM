Detailed Description

Quality report of a mesh (M15 F6): counts, angles, aspect ratios, edge lengths, the validity of curved cells and the tagging, and a check of a periodic pair of faces. The numbers are meant for a mesh dialog or a log line before the assembly, not for adaptivity. See docs/theory/mesh.md#mesh-report.
