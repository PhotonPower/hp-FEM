template<int N>
Real hpfem::materials::loss_density ( const Material &  material,
const Eigen::Matrix< Complex, N, 1 > &  e

Dimensionless loss density \( E^H\,\mathrm{Im}(\varepsilon)\,E \) of the field e with N = 2 (in-plane components, permittivity_tensor<2>) or N = 3 components; the time-averaged Joule heating is \( \tfrac12\omega\varepsilon_0 \) times it. For a symmetric ε the Hermitian part \( (\varepsilon - \varepsilon^H)/2i \) is the real matrix \( \mathrm{Im}\,\varepsilon \), so this is real; it reduces to \( \mathrm{Im}(\varepsilon_r)|E|^2 \) for an isotropic medium.

Permittivity tensor seen by the Dim-dimensional in-plane Nédélec space: the full tensor in 3D, the x–y block in 2D (the in-plane fields E_x, E_y with ∂_z = 0).

Exceptions
AnisotropicUnsupportedin 2D if the tensor couples the plane to z ( \( \varepsilon_{xz} \ne 0 \) or \( \varepsilon_{yz} \ne 0 \)): the in-plane field then drives E_z, which the 2D space does not carry (use the conical solver).
