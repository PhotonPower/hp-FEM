Detailed Description

Shared-memory parallel loops (OpenMP when the library was built with it, otherwise serial). Assembly and estimator loops run cell by cell with per-thread buffers; callers of parallel_for must make their bodies reentrant (no shared mutable state without a lock, per-thread accumulators merged afterwards). See docs/theory/solvers.md#parallel-assembly.
