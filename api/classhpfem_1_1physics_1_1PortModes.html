Detailed Description

template<int Dim>
class hpfem::physics::PortModes< Dim >

Modes, functionals and normalisations of one port; built by Scattering from the setup.

Constructor & Destructor Documentation

mesh::Tag  facet_tag,

Real  omega,
Index  num_modes,
int  extra_order = 2

Solves the cross-section problem of the facets tagged facet_tag with the materials of their inside cells at ω and keeps num_modes modes (3D: at most the guided ones). Quadrature on the port of degree 2p + extra_order.

Exceptions
InvalidArgumentfor a tag without boundary facets, a lossy material on the port, facets not on one straight line (2D) / plane (3D), ω ≤ 0 or num_modes < 1; Error if the 3D mode solver does not converge.
