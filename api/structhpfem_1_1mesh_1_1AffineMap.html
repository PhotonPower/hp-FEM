Detailed Description

template<int Dim>
struct hpfem::mesh::AffineMap< Dim >

Affine map \( x(\xi) = x_0 + J\,\xi \) from the reference simplex (vertices \( e_0 = 0, e_1, \dots, e_{Dim} \), see SimplexTopology) to a cell. Column \( i-1 \) of \( J \) is \( x(v_i) - x(v_0) \) in the cell's local vertex order.

det is signed: the local vertex order of a cell is not required to be positively oriented (orientation of shared entities is fixed by global vertex ids, ADR-0003), so integrals use volume() and the Piola transforms use det consistently.
