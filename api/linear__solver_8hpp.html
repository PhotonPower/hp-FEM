Detailed Description

Interface for the direct solvers of the assembled complex systems and the available backends: Eigen's SparseLU (always), MUMPS (HPFEM_ENABLE_MUMPS, sequential complex double build) and cuDSS on the GPU (HPFEM_ENABLE_CUDA, loaded at run time from the separate hpfem_gpu library). See docs/theory/solvers.md.
