Detailed Description

template<int Dim>
struct hpfem::physics::TriangulatedField< Dim >

The field on the n-fold subdivided mesh (mesh::subdivide): sub-vertices with their physical position (curved cells included), the sub-simplices by vertex index, the values per sub-vertex (one row each, components as in SampledField), and the parent cell and its tag per sub-simplex. Sub-vertices are not shared between parent cells, so discontinuities of the field across facets are preserved.
