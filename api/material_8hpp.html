Detailed Description

Non-dispersive materials given by relative permittivity and permeability (complex; with the exp(−iωt) convention lossy media have Im εr > 0), isotropic or with a symmetric 3×3 permittivity tensor (ADR-0015), and their assignment to the cells of a mesh by tag. Dispersion models live in the Python layer (hpfem.materials), which evaluates them to a Material per frequency.
