Detailed Description

template<int Dim>
class hpfem::io::FieldExporter< Dim >

Writes fields on the n-fold subdivided mesh as point data. The sub-mesh duplicates its points per parent cell, so discontinuities are preserved; parent cell data can be broadcast to the sub-cells. Choose subdivisions of the order of the polynomial degree to resolve the fields.
