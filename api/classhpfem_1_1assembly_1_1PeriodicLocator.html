Detailed Description

template<int Dim>
class hpfem::assembly::PeriodicLocator< Dim >

Partner lookup across the periodic faces for post-processing and the residual estimators: for a point x on a slave facet, the master cell containing x − a and the reference coordinates there, with the phase (field at x = phase × field at x − a). Groups of overlapping facets are formed as in bloch_constraints.
