Detailed Description

template<int Dim>
class hpfem::mesh::QuadraticGeometry< Dim >

Curved cell with the quadratic Lagrange map \( x(\xi) = \sum_i \lambda_i(2\lambda_i - 1)\, x_i + \sum_{e=(a,b)} 4\lambda_a\lambda_b\, m_e \) in barycentric coordinates \( \lambda \); \( x_i \) are the vertices in local order and \( m_e \) the edge nodes in local edge order (SimplexTopology<Dim>::kEdgeVertices). With \( m_e \) at the edge midpoints the map is exactly affine.
