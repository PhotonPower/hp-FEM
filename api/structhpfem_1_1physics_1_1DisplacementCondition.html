Detailed Description

template<int Dim>
struct hpfem::physics::DisplacementCondition< Dim >

Prescribed displacement components on the facets carrying tag: the components with components[i] set take value(x)(i) (zero without a value). All components zero clamp the facets; one zero component on an axis-aligned plane is a symmetry plane.
