Detailed Description

Hierarchical H1-conforming basis of arbitrary order on the reference simplex, with the polynomial order assignable per edge, face and cell. Formulas and ordering: docs/theory/h1-basis.md. Entity functions are evaluated in the global orientation of their entity (ADR-0003), so neighbouring cells see identical functions on shared entities and the DoF map needs no sign or permutation fix-ups.
