Detailed Description

Resonances (quasi-normal modes) of open structures: the eigenproblem \( \nabla\times(\mu_r^{-1}\nabla\times E) = k^2\varepsilon_r E \) with PEC walls and a PML that turns the outgoing-wave condition into complex-symmetric absorbing layers, so the eigenvalues \( k^2 = \omega^2/c_0^2 \) are complex. With the exp(−iωt) convention a decaying mode has \( \mathrm{Im}\,\omega < 0 \) and the quality factor is \( Q = \mathrm{Re}\,\omega / (-2\,\mathrm{Im}\,\omega) \). The pencil (S, M) with the stretched material tensors is solved by solvers::complex_eigenpairs_near around the target frequency. See docs/theory/maxwell.md#resonances.
