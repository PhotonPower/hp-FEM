Detailed Description

Analytic incident fields in a homogeneous background with real wavenumber k: plane waves and point (3D) / line (2D) dipoles, given as value and curl so that they serve as Dirichlet data, as scattered-field sources and as reference solutions. All solve \( \nabla\times\nabla\times E - k^2 E = 0 \) away from the source with the exp(−iωt) convention (outgoing waves). See docs/theory/maxwell.md#scattering-problems.
