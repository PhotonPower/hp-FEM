Detailed Description

Plane wave on a layered background for the conical solver (the stack normal is y, as for Scattering<2>): the 3D stack field restricted to the (x, y) plane with the invariant direction z carrying \( e^{i\beta z} \), β = k0 n sin θ sin φ (the azimuth φ rotates the in-plane wave vector about the normal; φ = 0 is in-plane incidence with β = 0).
