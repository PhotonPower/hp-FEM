Detailed Description

template<int Dim>
struct hpfem::mesh::Refined< Dim >

Result of one uniform refinement step. Parent vertices keep their ids; the vertex created on parent edge e has id parent.num_vertices() + e. Child cells are stored parent by parent: children of parent cell c are kChildren * c + i.
