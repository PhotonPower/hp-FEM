Detailed Description

template<int Dim>
struct hpfem::fespace::detail::EdgeKernel< Dim >

Scaled integrated Legendre data of the vertex pair (a, b): values and gradients of \( L_i^S(\lambda_b - \lambda_a, \lambda_a + \lambda_b) \) for i = 0..order (entries 0 unused).
