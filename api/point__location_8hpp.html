Detailed Description

Locating physical points in a mesh: which cell contains \( x \) and what are its reference coordinates \( \xi \) there. Needed for field evaluation at arbitrary points (detectors, line scans, mode overlaps) and for interpolation between meshes. Algorithm and tolerances: docs/theory/mesh.md#point-location.
