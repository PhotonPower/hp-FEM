Detailed Description

Polynomial absorption profile \( \hat\sigma(d) = \hat\sigma_{\max}(d/\text{thickness})^m \) with \( \hat\sigma_{\max} = -\frac{(m+1)\ln R_0}{2\,k_0\,n\,\text{thickness}} \), so that a wave at normal incidence returns from the far end with amplitude ratio \( R_0 \).
