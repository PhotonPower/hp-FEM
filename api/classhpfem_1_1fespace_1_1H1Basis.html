Detailed Description

template<int Dim>
class hpfem::fespace::H1Basis< Dim >

Hierarchical H1 basis of one cell. Function order: the Dim + 1 vertex functions, then the functions of edge 0, 1, …, then (3D) of face 0, 1, …, then the interior functions; within an entity by ascending polynomial degree (docs/theory/h1-basis.md).
