Detailed Description

Modal transparent boundary of a periodic conical problem (ADR-0015 §2, M19 S5b): a straight boundary line along the period in a homogeneous, possibly anisotropic, non-magnetic medium, where the unknown field consists of outgoing waves only (the scattered field below a structure on a half-space background, or above it). The boundary term \( \oint (n\times\nabla\times E)\cdot F\,ds \) is written with the Dirichlet-to-Neumann map of the half-space modes of every Fourier order (conical_modal_boundary_matrix), so it truncates the domain where a PML is unstable (a tilted crystal substrate, pml-backward-wave).
