Detailed Description

Relative material parameters of a medium: an isotropic permittivity εr or a symmetric permittivity tensor (a crystal, ADR-0015), and a scalar permeability μr.

The scalar accessors eps_scalar() and refractive_index() throw AnisotropicUnsupported for a tensor material: a feature that has not been migrated to tensors fails instead of computing with a wrong scalar. Tensor-aware code uses eps_tensor() / mu_inv_tensor(), which work for both kinds. Isotropic materials carry no tensor and stay as small and fast as before.
