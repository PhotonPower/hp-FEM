Detailed Description

Element and global assembly of the scalar form \( a(u,v) = \int_\Omega \alpha\,\nabla u\cdot\nabla v + \beta\,u\,v,\quad \ell(v) = \int_\Omega f\,v \) on the hierarchical H1 space, and error norms against an exact solution. Conventions: docs/theory/scalar-fem.md; test functions are not conjugated (complex symmetric systems, ADR-0002).
