Detailed Description

template<int Dim>
class hpfem::fespace::NedelecBasis< Dim >

Nédélec (first kind) basis of one cell. Function order: edge 0, 1, … (Whitney function, then the gradients ∇L_i^S for i = 2..p_e), then (3D) face 0, 1, …, then the interior functions; within faces / interiors by type (gradient, non-gradient twin, Whitney-type) and ascending degree, see docs/theory/nedelec.md.
