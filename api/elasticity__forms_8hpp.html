Detailed Description

Forms of small-strain linear elasticity on the vector H1 space (ADR-0016): Dim copies of the scalar hierarchical DofMap<Dim>, numbered component-major, \( u = (u_x | u_y | u_z) \) with the DoF i·N + k for component i and scalar DoF k (N = dofs.num_dofs()). The bilinear form and the loads are

\[ a(u, v) = \int C\,\varepsilon(u) : \varepsilon(v), \qquad \ell(v) = \int C\,\varepsilon^* : \varepsilon(v) + \int f\cdot v \]

with the stiffness C in Voigt notation: 3D order (xx, yy, zz, yz, xz, xy), 2D (xx, yy, xy) in plane strain, engineering shear strains (γ_ij = 2 ε_ij). Tractions are surface loads (physics::Elasticity). Real problems are assembled as complex with zero imaginary part (ADR-0016 §3). SI units: u [m], C and σ [Pa], f [N/m³]. See docs/theory/elasticity.md.
