Detailed Description

template<int Dim>
class hpfem::pml::Pml< Dim >

The absorbing layers of a problem: a PmlBox or a RadialPml, with the operations the solvers need (layer membership, Jacobian, effective tensors, resolution). Converts implicitly from both, so setup.pml = PmlBox<2>::uniform(...) keeps working.

True if the layers are invariant under the orthogonal map \( x \mapsto Qx + a \) at the given points: \( J(Qx + a) = Q J(x) Q^T \) up to tolerance relative to \( \max(1, |J(x)|) \). Symmetry reductions check this on the cells of the reduced mesh.
