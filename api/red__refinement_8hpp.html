Detailed Description

Child patterns of the red (regular) refinement of a simplex, shared by refine_uniform and AdaptiveMesh. Local nodes of a refined cell: the parent vertices 0..Dim, then the midpoint of parent edge k at Dim + 1 + k (SimplexTopology<Dim>::kEdgeVertices order). See docs/theory/mesh.md#refinement.
