Detailed Description

Gauss–Legendre and Gauss–Jacobi rules on [0,1] and collapsed (Duffy) Gauss–Jacobi rules on the reference triangle and tetrahedron. Formulas: docs/theory/quadrature.md. Rules of arbitrary order are generated by the Golub–Welsch algorithm, so there is no upper limit on the degree; order ≥ 2p+1 is required for mass terms (CLAUDE.md §6).
