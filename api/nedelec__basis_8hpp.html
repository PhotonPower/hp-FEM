Detailed Description

Hierarchical H(curl)-conforming Nédélec basis of the first kind on the reference simplex, arbitrary order, orders assignable per edge, face and cell, gradient and non-gradient functions explicitly separated. Formulas, ordering and the de Rham structure: docs/theory/nedelec.md#hierarchical-basis. Entity functions are evaluated in the global orientation of their entity (ADR-0003), exactly as H1Basis.

Values and curls are given on the reference element; the covariant Piola map of docs/theory/nedelec.md#mapping transfers them to a physical cell.
