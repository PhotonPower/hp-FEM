◆ parallel_for()

template<class Body >
void hpfem::parallel_for ( Index  n,
Body &&  body 
)

Runs body(i, thread) for i in [0, n) on all threads with dynamic scheduling. An exception thrown by the body stops the loop (remaining indices are skipped) and is rethrown on the calling thread once all threads have finished; with several throwing bodies the first one caught wins.

◆ spherical_bessel_j() [1/2]

std::vector< Complex > hpfem::spherical_bessel_j ( int  max_order,
Complex  z 
)
inline

\( j_0(z), \dots, j_N(z) \) for complex z (e.g. inside an absorbing sphere) by downward recurrence \( j_{n-1} = \frac{2n+1}{z} j_n - j_{n+1} \) started well above N and normalised with \( j_0 = \sin z / z \) (stable for all orders, unlike the upward recurrence). For |z| < 1e-300 the limit \( j_n(0) = \delta_{n0} \) is returned.

Exceptions
InvalidArgumentfor max_order < 0.
