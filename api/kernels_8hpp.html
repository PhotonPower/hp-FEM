Detailed Description

Shared building blocks of the hierarchical H1 and H(curl) bases: the edge kernel \( L_i^S(\lambda_b - \lambda_a, \lambda_a + \lambda_b) \) and the bubble factor \( \lambda\,P_j(2\lambda - 1) \), both with reference gradients assembled from the barycentric gradients. Internal; see docs/theory/h1-basis.md.
