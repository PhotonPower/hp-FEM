Detailed Description

Reference simplex of the finite-element spaces: unit triangle (0,0),(1,0),(0,1) and unit tetrahedron (0,0,0),(1,0,0),(0,1,0),(0,0,1), with the binding local numbering of edges and faces (mesh::SimplexTopology, docs/theory/nedelec.md), barycentric coordinates and facet geometry. Everything here is dimensionless.
