# hp-FEM

An open-source, adaptive **hp-finite-element** suite for nano-optics: high-order Nédélec
elements, rigorous a-posteriori error estimation and perfectly matched layers for
time-harmonic Maxwell problems — scattering, resonances and waveguide modes.
